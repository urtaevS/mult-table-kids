# 🚀 Таблица умножения — Учимся играя

Весёлое приложение, которое помогает детям выучить таблицу умножения играючи.
Яркие экраны, дружелюбный маскот и маленькие награды превращают зубрёжку в игру. 🎉

## ✨ Что внутри

- 📚 **Учим** — наглядный разбор каждой таблицы, шаг за шагом
- 🏋️ **Тренируем** — практика примеров с подсказками и подбадриванием
- 🎯 **Проверяем** — мини-тесты с мгновенными результатами
- 🏆 **Достижения** — значки за старание и прогресс
- 📱 **PWA** — добавь на главный экран и учи без интернета

## 🌐 Живой пример

Готовая версия уже живёт здесь: **https://urtaevs.github.io/mult-table-kids/**

## 🤖 Android (APK)

Приложение собирается в нативный `.apk` прямо в GitHub Actions.
При каждом пуше в `main` (и по тегу `v*`, и вручную через `workflow_dispatch`)
запускается сборка **debug‑APK**, а готовый файл `app-debug.apk` (~5 МБ)
появляется в разделе **Artifacts** соответствующего запуска Actions —
его можно скачать и установить на телефон для теста. Сборка использует
JDK 21 и Android SDK (API 36), так что на локальной машине ничего
дополнительно ставить не нужно. 🤖

Как скачать и установить:
1. Открой **Actions → «Build Android APK»** в репозитории на GitHub.
2. Зайди в последний успешный запуск и пролистай вниз до **Artifacts**.
3. Скачай `app-debug-apk`, разархивируй — получишь `app-debug.apk`.
4. На телефоне разреши «Установку из неизвестных источников»
   (Настройки → Безопасность) и открой скачанный файл.

Локально (если стоит Android Studio / SDK + JDK 21):

```bash
npm run android:build   # собрать веб-часть и синхронизировать с Android-проектом
```
